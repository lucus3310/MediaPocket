# MediaPocket 0.3 逐幀與縮放試用

沿用同一個 Bundle ID 覆蓋自簽安裝，保留既有檔案；重要媒體另有備份後再更新。

1. 開啟一段 MP4，直接按「下一幀」：播放應暫停，且每次只往下一個畫格。再按「上一幀」確認可退回。逐幀與十秒快轉是不同的按鈕。
2. 測試可變幀率影片：相鄰幀的時間差可能不同，不能只用固定 1/30 秒判斷。介面顯示時間而不虛構連續幀編號。
3. 左上角選單切換 VLC，重複前後逐幀。來源無法反向逐幀時應有訊息，不應以大幅跳轉替代。
4. 在影片畫面雙指放大，最高 8 倍；放大後以一指拖曳看不同區域。輕點兩下或使用右上倍率選單回到 1 倍。
5. 暫停在同一幀，放大至 8 倍，確認畫面持續可見。旋轉螢幕後會重新適合畫面並重置 1 倍。
6. 測試 1080p／4K H.264 或 HEVC，再測 MKV／WebM。記錄所用引擎、有無黑畫面、跳幀、卡頓、無聲或過熱。

「硬體優先」表示解碼策略。是否真正使用硬體，取決於編碼、裝置與可用資源；Simulator 結果不能證明 iPhone 的硬體解碼狀態。

回饋請包含 App 與 iOS 版本、檔案容器／已知編碼、使用的引擎，以及逐幀方向或縮放倍率。不需提供帳號密碼。
