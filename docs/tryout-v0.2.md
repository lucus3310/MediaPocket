# MediaPocket 0.2 試用項目

請用與前版相同的 Bundle ID 覆蓋安裝，先確認備註與原有檔案仍存在。首次更新前，將重要媒體另外保留一份。

## 檔案管理

1. 右上角「＋」建立「旅行 影片」，進入後匯入一個檔案。
2. 同一個檔案連續匯入三次，確認檔名出現 `(2)`、`(3)` 且原檔仍存在。
3. 長按檔案測試重新命名、製作副本、移動、分享；嘗試含中文和空白的名稱。
4. 將一個檔案移到垃圾桶，再從右上角「⋯ → 垃圾桶」還原。
5. 先刪除資料夾、再建立同名資料夾，還原舊資料夾時應新增編號，而不是覆蓋新資料夾。
6. 測試搜尋及名稱／最新／大小排序。從系統「檔案」改名後回 App 應重新整理。

垃圾桶會保留資料並佔用空間，本版沒有自動清空或永久刪除按鈕。

## 播放

1. 先測一個 H.264／AAC MP4，再測自己持有的 MKV、AVI、WebM 或其他格式。
2. 播放器左上角可手動切換系統播放器和 VLC。自動模式遇到系統不支援時會嘗試 VLC。
3. VLC 測試暫停、進度拖曳、前後十秒、倍速、旋轉螢幕。
4. 播放一段時間後按「完成」，重新開啟同一個檔案，確認續播位置。
5. 記下黑畫面、只有聲音、無聲、字幕問題或解碼失敗時所用的引擎與檔案資訊。

## 回饋內容

- 手機 iOS 完整版本、App 版本。
- 操作步驟、預期結果、實際結果。
- 播放問題附副檔名及已知的影音編碼；兩個引擎是否都會發生。
- 不需要提供 Apple 密碼、Cookie 或登入驗證碼。

本版尚未加入 FFmpeg 下載、四平台連結解析、獨立音軌／字幕選單或背景播放保證。
