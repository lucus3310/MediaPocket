# MediaPocket 0.10.1（12）：取得畫質時保留在 App

本版針對按「取得可用畫質」卻開啟 YouTube／黑色全螢幕播放器的回饋，限制內建解析器的 WebKit：只允許內部空白文件、阻擋網站／App 導向與開新視窗、暫停媒體播放並攔截播放／全螢幕呼叫。保留 JavaScript 運算、訊息回傳及格式能力查詢。這些限制只套用到解析器，既有 AVPlayer／VLC 播放器不受影響。

## 更新及試用

1. 使用與目前相同的 Bundle ID 免費自簽，覆蓋安裝 **0.10.1（12）**，保留資料。
2. 進入「下載」，貼上 YouTube 連結，可按「收起鍵盤」。
3. 按「取得可用畫質」，應留在下載頁；成功後在任務卡選畫質、fps、編碼及輸出格式，再按「開始下載與合併」。
4. 解析失敗時顯示錯誤，保留任務狀態供查看；不以開啟外部網站作為下載備選。
5. 完成後至「檔案庫 → App 內檔案 → Downloads」管理與播放。

FFmpeg、ffprobe、CPython 與 yt-dlp 均隨 App 打包，不需 a-Shell 或捷徑。執行時保持 MediaPocket 在前景。來源、登入及地區會影響可取得的畫質。來源資料夾與既有影片仍預設原位置讀取，不另存影片副本；新下載與合併暫存會佔用容量。

完整的引擎、容量、免費建置及授權說明沿用 [0.10.0 文件](tryout-v0.10.0.md)。本版驗證紀錄見 [0.10.1 驗證](validation-v0.10.1.md)。
