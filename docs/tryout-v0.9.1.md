# MediaPocket 0.9.1：鍵盤與下載入口修正

沿用原 Bundle ID 自簽覆蓋安裝，App 設定中的版本應為 0.9.1。播放器、來源資料夾與下載引擎沿用 0.9，不需要先刪除 App。

## 從目前畫面繼續

當畫面顯示「首次使用：設定免費下載工具」，代表 App 尚未讀到下載環境已就緒的狀態，不代表影片已下載。

1. 收起鍵盤，按「先完成下載設定」或「首次使用：設定免費下載工具」。
2. 按「1. 授權下載交接資料夾」，在免費完整版 a-Shell 的選擇器進入「我的 iPhone → MediaPocket → MediaPocketBridge」，再按開啟。
3. 返回 MediaPocket 的設定，按「2. 安裝／更新解析元件並檢查 FFmpeg」。在 a-Shell 等待檢查完成；如果顯示錯誤，保留最後的錯誤文字供排查。
4. 返回 MediaPocket，按重新整理。就緒後主要按鈕會變為「取得可用畫質」；連結會保留，不需要重貼。
5. 按取得畫質，等待 a-Shell 解析。回 App 點「來源畫質」旁的箭頭選擇，再選儲存格式，按「開始下載與合併」。下載期間保持 a-Shell 在前景。
6. 完成後返回 App，在任務按「播放／管理下載成品」。

如果沒有成功取得就緒狀態，請看 a-Shell 的最後錯誤，而不是重複按下載。這版不會繞過初始化檢查，也不會將「已開啟 a-Shell」當作下載完成。

## 鍵盤修正

- 輸入框旁新增「收起鍵盤」，鍵盤工具列也提供同名按鈕。
- 可向下滑動清單收合鍵盤；按設定或主要動作也會先取消輸入焦點。
- 收合不清除連結。未就緒時，主要動作直接開啟設定，並顯示下一步指引。

CI 的 XCUITest 會實際叫出 iOS Simulator 軟體鍵盤，輸入連結、收合兩次並確認連結保留，再檢查未就緒的按鈕能開啟設定頁及兩個設定動作。這不等於實體 iPhone 的中文鍵盤或 a-Shell 下載已驗證，仍需你試用。
