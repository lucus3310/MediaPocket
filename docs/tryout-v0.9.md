# MediaPocket 0.9 試用

使用相同 Bundle ID 自簽覆蓋安裝，版本應為 0.9.0。保留原位置檔案庫、整個資料夾、逐幀播放器與 8 倍縮放。這版仍使用免費完整版 a-Shell，沒有捷徑依賴，沒有遠端付費服務。

## 設定與下載

1. 到「下載 → 齒輪」，首次授權「我的 iPhone → MediaPocket → MediaPocketBridge」子資料夾，再安裝／更新解析元件。新版會同時準備 `runner.py` 和 `download_engine.py`。
2. 保持「分段加速與續傳」開啟，預設 4 段。若來源限流，降成 1–2 段；只有 HLS／DASH 分段會並行，一般 HTTP 不強制分塊。
3. 貼上支援平台的 HTTPS 單一影片／貼文連結，按取得畫質。解析後返回 App，點任務卡片的「來源畫質」。
4. 在原生選單篩選影片／音訊、解析度、影格率及編碼，也可搜尋 HDR、AV1、2160 或 60 fps。4K／8K 只有來源有提供時才出現。多段貼文列共同格式，或選各片最高畫質。
5. 選儲存格式並開始下載。保持 a-Shell 在前景；完成後返回 App，在任務按「播放／管理下載成品」直接進檔案庫。

## 格式選擇

| 選項 | 行為 |
|---|---|
| 自動無損 MP4／MKV | 預設；相容時 MP4，否則 MKV，不重新編碼 |
| 原編碼 MKV／MKA | 保留來源影音編碼，合併影音軌 |
| MP4・需要時自動轉碼 | 相容軌複製，其餘轉 H.264／AAC |
| H.264／HEVC | 明確轉碼選項；優先可用 VideoToolbox，亦可由其允許軟體回退 |
| WebM・原編碼 | 需 VP8／VP9／AV1 與相容音訊；不相容時拒絕，不偷換格式 |
| M4A／MP3／FLAC／WAV | 純音訊選項；相容 AAC／ALAC 可複製進 M4A，其餘按可用編碼器轉碼 |

轉碼不會提升原始畫質或音質，也可能增加耗電、時間或檔案大小。HDR 來源請選原編碼或自動無損；沒有 tone mapping 的轉碼會拒絕。缺少所需編碼器時會在開始傳輸前報錯，可改選原編碼。選取來源的 fps，不會補幀成不存在的高影格率。

## 中斷與空間

取消或失敗後可按「重試／續傳相同任務」。會重取有效來源，對相同來源／格式嘗試續傳；若平台改變內容、移除畫質或伺服器不支援 Range，可能需要重新下載。新選畫質會建立新任務，不混用不同格式的暫存。

分段模式先下載軌道，再合併成品，期間需要軌道與成品空間；成功後清理軌道暫存，失敗時保留供重試。關閉加速時使用直接 FFmpeg 原編碼 MKV／MKA 路線，可減少中間軌道暫存，但不處理 DASH 分片。外部來源影片仍原位置開啟，不另外複製。

## 平台與驗證範圍

已接入 YouTube、Instagram、Threads、Bilibili、TikTok、X／Twitter、Vimeo、Dailymotion 的個別影片連結路由與 yt-dlp extractor。登入 Cookie 可按平台放在設定指示的資料夾。來源、區域、登入、限流、平台驗證均可能影響實際可用格式；不承諾每個影片都有 4K／8K。沒有 DRM 解密或付費串流繞過功能。

CI 會測本地 HTTP 的分軌下載、HLS、Range 續傳、4K60 與 8K 原編碼保留、MP4 轉碼及音訊輸出，並測檔案庫匯入、舊任務相容、逐幀、縮放、書籤重啟與原生畫面。這些測試不等於實體 iPhone 的硬體編碼、長影片、背景行為或各平台登入下載驗證；請先試一段短片，再試長影片或高解析度。
